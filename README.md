# dqn-c51 

Comparison of DQN and C51 agents on the MinAtar SeaQuest environment. 

The code is inspired by cleanrl implementations (https://github.com/vwxyzjn/cleanrl), which in turn is also partly based on Stable Baselines 3. I modified the code for the purposes of this project, renamed things based on personal preference, removed environment wrappers for compatibility with MinAtar and, finally, adjusted the neural network architecture to the particular MinAtar environment. 

Using `torch`, `gymnasium`, `minatar`.
